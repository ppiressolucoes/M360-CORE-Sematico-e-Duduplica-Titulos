## Como adicionar outros arquivos

1. Abra esta pasta no GitHub.
2. Clique em **Add file → Upload files**.
3. Selecione os arquivos e conclua em **Commit changes**.
4. Copie o endereço da pasta ou de um arquivo e compartilhe na conversa.

Endereço desta pasta: https://github.com/ppiressolucoes/M360-CORE-Sematico-e-Duduplica-Titulos/tree/main/alertas/2026-10-20

Como o repositório é público, use arquivos `.txt` ou `.html` contendo apenas o corpo do alerta, sem cabeçalhos de e-mail, remetentes/destinatários, credenciais ou chaves operacionais. Os `.msg` originais enviados no chat permanecem fora do Git.

Para permitir a análise, conserve título e URL do candidato, versões e modo exibidos, TOP3 com títulos e origens, scores, tokens e limites usados. Prefira nomes únicos dentro de cada lote, como `alerta-001.txt`.
